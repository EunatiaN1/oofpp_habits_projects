Phase 2 task 1

Pomodoro Habit Time Tracker

A practical productivity app that combines timed focus sessions with personal habit tracking and reflection.

  • Users can work in structured 25-minute focus sessions and rest periods.

  • Habit tracking supports daily and weekly routines in one simple tool.

  • Progress and analytics help users reflect on consistency and improvement.

Quick overview

“Stay focused, stay consistent.”

Design

Project goal

The app is designed to help users manage time more effectively while also improving their routines and habits.

1

Support deep work through a clear and familiar Pomodoro structure.

2

Track daily and weekly habits with date-based rules and timestamped history.

3

Make the experience lightweight, easy to test, and easy to keep using.

Architecture

System structure

The project is split into four clear layers so it stays maintainable and easy to extend.

  • Timer layer: 25-minute focus sessions, 5-minute breaks, and 15-minute long breaks after every fourth session.

  • Storage layer: SQLite stores habit details and timezone-aware completion timestamps.

  • Analytics layer: Completion rates and streaks are calculated using separate functions.

Design principle

Keep each part simple, testable, and easy to understand.

Implementation

Development flow

The app was built in a straightforward order to support stable development and testing.

1

Define the user need and establish the functional requirements.

2

Create the habit model and work-session logic.

3

Implement SQLite persistence and seeded habit data.

4

Add analytics and command-line commands for review and management.

Features

User experience

The app gives users practical ways to manage habits and monitor performance.

  • Create, delete, and complete habits.

  • Review habit progress and timestamped completion history.

  • Analyse daily and weekly trends using built-in reporting.

  • Use a simple, accessible workflow from the command line.

Reflection

What this project demonstrates

The project shows a complete design-to-implementation process and a thoughtful approach to productivity tooling.

  • The modular design keeps the code easier to understand and maintain.

  • SQLite provides a reliable local database without unnecessary complexity.

  • Analytics are separated from storage so the logic stays clear and testable.

Final thought

A simple tool can still support meaningful daily discipline.
